  • コメント・配置・切り抜き・個別色はこの端末のブラウザ内だけに保存します。
  • テンプレ画像はこのブラウザの IndexedDB に保存します。

  • APIキーが流出すると、そのキーの権限次第で第三者がNotion内の情報を閲覧・変更できる可能性があります。可能なら読み取り専用のIntegrationを使用してください。

使い方・安全性

はじめに

このページは、Notionのデータを読み込んでマギアマトリクス上に配置・編集するためのツールです。元のNotionデータへ書き込みは行いません。

必要なもの

  • 中継Worker URL
  • Notion APIキー
  • Notion データベースURL または ID
  • 読み込みたいプロパティ名
APIキーの取得方法について

APIキーの発行・取得・権限設定の方法は、各サービスの公式案内を確認してご自身で設定してください。このページではAPIキーの作り方・取得方法は案内しません。

Notionを読み込む

  1. 中継Worker URLを入力します。
  2. Notion APIキーを入力します。
  3. Notion データベースURLまたはIDを入力します。
  4. 名前・画像・URL・文字色など、使いたいプロパティ名を入力します。
  5. 「Notionを読み込む」を押します。

テンプレ画像

マトリクス画面の左半分・右半分に、それぞれテンプレ画像をドラッグ＆ドロップできます。左右は別々に保存されます。

アイコン編集

  • アイコンはドラッグして配置できます。
  • アイコンを押すとコメント・個別色・切り抜きを編集できます。
  • 画像プロパティがない場合は、Notionページアイコン、その次にfaviconを使用します。

保存先

  • コメント・配置・切り抜き・個別色・接続設定は、この端末のこのブラウザ内に保存されます。
  • APIキーは「この端末に保存する」をONにした場合だけ Local Storage に保存されます。
  • 左右のテンプレ画像は IndexedDB に保存されます。
  • 別ブラウザ・別Chromeプロフィール・別端末には自動で引き継がれません。

Chromeで保存内容を確認する場所

開発者ツール → Application → Local Storage → このサイトのURL

テンプレ画像は Application → IndexedDB → magiaMatrixDB で確認できます。

安全性について

  • このツールはNotionの作成・更新・削除APIを実装していません。
  • 中継WorkerはAPIキーを保存しません。Notionを読む処理の間だけ利用します。
  • APIキーを端末保存するかどうかはユーザーが選べます。
  • 共有PC・公共端末ではAPIキー保存をOFFにしてください。
  • 可能なら読み取り専用のIntegration/APIキーを使用してください。

APIキーが流出すると

  • そのキーに許可された範囲で、第三者にデータを閲覧される可能性があります。
  • 書き込み権限があるキーなら、別のツールから変更・削除に悪用される可能性があります。
  • 漏れた疑いがある場合は、サービス側ですぐにキーを無効化・再発行してください。
重要

「このツールが書き込みをしないこと」と「APIキー自体に書き込み権限がないこと」は別です。APIキーにはサービス側で設定された権限がそのまま付きます。
