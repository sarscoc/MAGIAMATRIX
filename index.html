接続設定

共有PC・他人が触れる端末ではOFF推奨。可能なら読み取り専用APIキーを使用してください。

このアプリの安全性とAPIキーについて
  • 外部データへの通信は GET のみで、POST / PUT / PATCH / DELETE は実装していません。
  • コメント・配置・切り抜き・色設定は、このサイトのブラウザ領域にだけ保存します。
  • APIキーは「この端末に保存する」をONにした場合のみ、このブラウザの localStorage に保存します。
  • 保存したAPIキーを作者のサーバーへ送信する処理や、アクセス解析コードは入れていません。
  • APIキーはデータ取得時に、あなたが指定したAPIへ送信されます。
APIキーが流出すると何が危険？
  • APIキーは、サービスによっては「あなたの権限そのもの」として扱われます。
  • 流出すると、第三者がそのAPIキーを使って、あなたが閲覧できるデータを読み取れる可能性があります。
  • 書き込み権限のあるAPIキーなら、第三者が別のツールからデータを変更・削除できる可能性があります。
  • 有料APIでは、利用回数や料金枠を第三者に使われる可能性があります。
  • このアプリがGETしか送らない設計でも、APIキー自体に強い権限が付いている場合、そのキーを盗んだ第三者は別の場所で悪用できます。
保存先はどこ？
  • APIキー（保存ONの場合）・コメント・配置・切り抜き・色設定は、この端末の、このブラウザの、このサイト専用の Local Storage に保存されます。
  • 通常の「ダウンロード」フォルダや「ドキュメント」フォルダにファイルとして保存されるわけではありません。
  • Chromeで中身を確認する場合は、PC版Chromeでこのサイトを開き、開発者ツール → Application → Local Storage → このサイトのURL を開くと確認できます。
  • Chromeの別プロフィール・別ブラウザ・別端末には自動では引き継がれません。
  • ブラウザ側でこのサイトの「サイトデータ」を削除すると、ここに保存した内容も消えます。
安全に使うために
  • 可能なら「読み取り専用」のAPIキーを使ってください。
  • 共有PC・公共端末・第三者が触れる端末では、APIキー保存をOFFにしてください。
  • 信頼できる公開先のHTMLでのみAPIキーを入力してください。
  • 流出した可能性がある場合は、すぐにAPIキーを無効化・再発行してください。
  • ブラウザのサイトデータ削除、または下の「保存したAPIキーを削除」で、この端末に保存したキーを消せます。
重要：「このアプリが書き込みをしないこと」と「APIキー自体が安全であること」は別です。APIキーには、そのサービス側で設定された権限がそのまま付いています。
