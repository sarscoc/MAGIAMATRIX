MAGIA MATRIX の使い方

このツールは Notion API を使ってデータを読み込みます。Notion APIキーと、対象のデータベースURL / IDを入力し、「読込 / 更新」を押してください。

データベースURL / ID

読み込みたいNotionデータベースのURLを入力します。公開用の共有URLでも利用できます。 URLの代わりにデータベースIDを入力することもできます。

読み込み項目について

名前（該当プロパティ）
キャラクター名など、一覧に表示したい名前が入っているNotionのプロパティ名を指定します。通常は 名前 などを指定します。

画像（該当プロパティ）
アイコンとして使う画像が入っているNotionのプロパティ名を指定します。

文字色（該当プロパティ・任意）
名前やコメントに使いたい色を指定するプロパティです。使わない場合は空欄でも構いません。

整列（数字のみ・任意）
アイコン一覧を数字の小さい順に並べたい場合に使います。Notion側に 1、2、3…のような数字プロパティを用意し、そのプロパティ名を指定してください。使わない場合は空欄で構いません。

faviconでアイコンを作る

チェックすると画像プロパティを使わず、Notionページ側に設定したページアイコンを読み込みます。チェックを外すと「画像（該当プロパティ）」の画像を使用します。

文字色プロパティについて

文字色は #E95464 のようなカラーコードだけでなく、文章や装飾コードの中に含まれていても読み取ります。例：\\colorbox{#e95464}{...}。複数のカラーコードが含まれる場合は、最後に見つかった色を使用します。

アイコンの配置・配置解除

左のアイコン一覧からテンプレへドラッグすると配置できます。配置済みアイコンを左のアイコン一覧側までドラッグして離すと、テンプレ上から配置解除できます。コメントや切り抜き設定は残るので、あとで再配置できます。

アイコンの切り抜き

そのまま表示では画像を切り抜かず、元画像全体を表示します。

丸に切り抜き / 角丸四角に切り抜きでは、アイコン一覧の画像をクリックすると切り抜き位置を調整できます。ドラッグで位置、マウスホイールやスライダーで拡大・縮小し、「保存」で位置を確定します。

コメント

テンプレ上のアイコンをダブルクリックするとコメントを編集できます。コメントの上下左右の位置もアイコンごとに変更できます。

画像保存

「画像保存（SS）」を押すと、現在のテンプレ・アイコン・名前・コメントをPNG画像として保存します。

画像や表示がいつもと違う、保存結果の挙動が怪しい場合は、いったん 「読込 / 更新」 を押して最新データと画像を読み込んでから、もう一度保存してみてください。

このブラウザへの保存について

読み込んだデータ、配置、コメント、切り抜き、表示設定、テンプレ画像、取得したアイコン画像などは、このブラウザ内の Local Storage / IndexedDB に保存されます。

永久保存ではありません。 ブラウザのサイトデータ削除、閲覧データ削除、端末変更、ブラウザ変更、プライベートブラウズなどで消える場合があります。大切な完成画像はPNGとして別途保存してください。

作者のサーバーへ、コメントやテンプレを保存する処理はありません。

Chromeで保存内容を確認する場合

開発者ツール → Application → Local Storage → このサイトのURL

テンプレ画像や取得したアイコン画像は Application → IndexedDB → magiaMatrixDB で確認できます。

APIキーを保存

MAGIA MATRIXはNotionのデータを読み込むために Notion API を使用します。

APIキーをこの端末に保存しますか？

保存先は、この端末・このブラウザ・このサイト専用の Local Storage です。作者のサーバーには保存しません。ただし、同じサイト上で悪意あるJavaScriptが実行された場合などには読み取られる可能性があります。

APIキーについて

  • APIキーが流出すると、そのキーに許可された範囲で第三者にデータを閲覧される可能性があります。
  • 書き込み権限のあるキーは、別のツールから変更・削除に悪用される可能性があります。
  • 可能なら読み取り専用のIntegrationを使用してください。
  • 漏れた疑いがある場合は、すぐに無効化・再発行してください。

APIキーの発行・権限設定についてはNotionの公式案内をご確認ください。
