APIキーについて

ここにはNotionのAPIキーを入力します。APIキーはNotionのデータを読むための認証情報です。

APIキーの取得方法について

APIキーの発行・取得・権限設定の方法は、各サービスの公式案内を確認してご自身で設定してください。このページではAPIキーの作り方・取得方法は案内しません。

接続について

利用者はWorker URLを入力する必要はありません。中継先は公開者がこのHTML内に一度だけ設定します。利用者が入力するのはNotion APIキーとデータベースURL/IDです。

読み込みデータの保存

Notionから一度読み込んだ名前・ページURL・文字色・整列番号などは、このブラウザに自動保存します。次回は前回データを自動表示するので、毎回APIを読む必要はありません。「読込 / 更新」を押したときだけ最新のNotionデータを取り直します。

Notionの画像URLは期限切れする場合があります。画像だけ表示されなくなった場合は「読込 / 更新」で最新URLを取り直してください。

保存について

  • APIキーは「保存する」を選んだ場合のみ、このブラウザの Local Storage に保存できます。
  • コメント・配置・切り抜き・表示設定もこのブラウザ内に保存されます。
  • テンプレ画像は IndexedDB に保存されます。
  • 作者のサーバーへ保存する処理はありません。

Chromeでの確認場所

開発者ツール → Application → Local Storage → このサイトのURL

テンプレ画像は Application → IndexedDB → magiaMatrixDB で確認できます。

faviconでアイコンを作る

チェックすると画像プロパティを使わず、Notionページ側のアイコンを読み込みます。チェックを外すと画像プロパティ欄が使えます。

文字色プロパティについて

文字色は #E95464 のようなカラーコードだけでなく、文章や装飾コードの中に含まれていても読み取ります。例：\colorbox{#e95464}{...}。複数のカラーコードが含まれる場合は、最後に見つかった色を使用します。

APIキーの危険性

  • APIキーが流出すると、そのキーに許可された範囲で第三者にデータを閲覧される可能性があります。
  • 書き込み権限のあるキーなら、別のツールから変更・削除に悪用される可能性があります。
  • 可能なら読み取り専用のIntegrationを使用してください。
  • 漏れた疑いがある場合は、すぐに無効化・再発行してください。
APIキーをこの端末に保存しますか？

保存先は、この端末・このブラウザ・このサイト専用の Local Storage です。作者のサーバーには保存しません。ただし、同じサイト上で悪意あるJavaScriptが実行された場合などには読み取られる可能性があります。
